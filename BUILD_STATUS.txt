FilterBridge Lab 0.3.2 — dual local image classifiers

Source validation completed in the authoring environment:
- 28 pure-Java core tests passed using a Java 17 test harness.
- Python exporter scripts passed py_compile.
- New Owen runtime classes compiled against API-compatible Android/ONNX stubs for Java syntax/type-shape checks.
- Android manifest XML and GitHub Actions YAML syntax checked.
- Full Android Gradle build was NOT executed in this environment (Android SDK/Gradle are unavailable).

- Device inference for both models is NOT yet verified.

Do not call this release production-ready. The app supports experimental still-image classification only. Video, music, speech/profanity, alcohol, drugs, gambling, complete violence, and flirting/interaction analysis are not implemented. Category coverage remains incomplete and policy must remain fail-closed.
